\section{Course code}

The directory \texttt{codigo/} contains the demos used in the lectures:
\begin{itemize}
  \item \texttt{icp\_demo}: point-to-point and point-to-plane ICP with outlier rejection, scenarios with
  partial overlap and noise, and an interactive viewer (used for \cref{fig:icp-conv,fig:icp-basin});
  \item \texttt{global-registration} (package \texttt{gr}): Harris 3D, spin images, correspondence
  grouping and 4PCS (used for \cref{fig:harris,fig:spin});
  \item \texttt{qem\_demo}: incremental decimation with QEM, shortest-edge and clustering criteria and
  surface distance metrics (used for \cref{fig:qem-levels,fig:qem-compare});
  \item \texttt{subdiv\_demo}: Loop, Catmull--Clark and Doo--Sabin subdivision on polygon meshes (used for
  \cref{fig:subdivision,fig:loop-bunny});
  \item \texttt{recon\_demo}: surface reconstruction methods;
  \item \texttt{rep3d}: an interactive application for 3D representations;
  \item \sloppy stand-alone scripts on Laplacians and filtering (\texttt{laplacian.py},
  \texttt{mesh\_filtering.py}), parameterization (\texttt{parameterization.py}), spectral descriptors
  (\texttt{shapeDNA.py}, \texttt{gps.py}, \texttt{heat\_kernel\_signature.py},
  \texttt{hks\_matching.py}, \texttt{biharmonic.py}) and registration (\texttt{registration.py});
  \item \texttt{datos/}: the TOSCA cats and horses with precomputed eigenpairs.
\end{itemize}
The meshes used in the figures come from \texttt{modelos/} (TOSCA cats and horses in several poses,
which share their vertex ordering and therefore provide ground-truth correspondences, an elephant and
ModelNet airplanes) and from the data folders of \texttt{icp\_demo} and \texttt{subdiv\_demo} (bunny,
armadillo, cow, fandisk, Max Planck, Spot).

\section{Figure scripts}

The scripts in \texttt{apuntes/scripts} use only NumPy, SciPy and Matplotlib for the geometry
and a small orthographic software renderer, plus Open3D (decimation, ray casting, screened Poisson),
PyMeshLab (remeshing, hole closing), scikit-image and scikit-learn where noted. The shared library
\texttt{gp.py} contains mesh loading and normalisation, cotangent and mass matrices, eigensolvers,
curvature, geodesics (heat method and Dijkstra), marching cubes helpers and the renderer.

\paragraph{Running.} Install the Python packages listed in \texttt{apuntes/requirements.txt} (on Linux,
PyMeshLab also needs the system library \texttt{libopengl0}). Each script regenerates all its figures,
or only the functions named on the command line:
\begin{lstlisting}[language=bash,numbers=none]
cd apuntes/scripts
python fig_ch10_13.py                       # all figures of chapters 10-13
python fig_ch14_16.py fmap_figures          # only the functional map figures
\end{lstlisting}
The spectral scripts cache the eigenpairs in a temporary folder. The heaviest functions (the
functional map pipeline, Super4PCS, the reconstruction comparison) take one to two minutes each on a
laptop.

\paragraph{Building the PDF.} The notes are plain \LaTeX{} (\texttt{book} class, \texttt{natbib},
TikZ, \texttt{algorithm2e}, \texttt{tcolorbox}); \texttt{make} in \texttt{apuntes/} runs
\texttt{latexmk -pdf main.tex}.
